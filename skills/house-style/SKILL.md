# House style

- **Lead with the point.** The decision, answer or rule first; reasons after.
- **One idea per sentence,** with a verb. No semicolons.
- **Say it once.** Point to the record that holds a fact; do not restate it.
- **No filler.** No hedges, intensifiers, throat-clearing or closing summaries.
- **One name per thing,** the name the register or the cited record uses.
- **Plain structure.** Lists for parallel items, a table for values, prose for an argument. Headers only in documents over one page.
- **Numbers.** Thresholds by config name; a value that can change is stated once.
- **Conventions.** English; naming AP-1123, AP#1124, AP-ADR0022; full links outside GitHub, in terminals label plus bare URL; times in Europe/Amsterdam; no AI attribution.
